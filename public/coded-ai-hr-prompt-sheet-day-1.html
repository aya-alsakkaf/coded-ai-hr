How to use this
  1. Watch the trainer first. Then find the same card here.
  2. Download the file on the card. In Copilot Chat, start a new chat and attach it (the + or paperclip button).
  3. Click COPY, paste the request into Copilot, then press Enter.
  4. Check the answer against the file before you trust it: dates, numbers, names and rules.

Answers vary. Copilot may word things differently from the trainer's screen. That is normal, and it is why we check. Requests you write yourself are not on this sheet: write them with the checklist, and use the hints on the day's lab page if you are stuck. Use only the fictional Mutla files here, or green tasks from your own work.

Build a request, part by part

Watch it in the slide. The trainer runs it with the room.
The checklist request
You are a Personnel officer at Mutla Oil Company. The year is ending. Some employees do not know that unused leave over the limit is lost. Write a short reminder email to all staff about carrying over annual leave. Use the attached mutla-leave-policy-2026.docx, section 4. Use only section 4. Keep every number and date exactly as written. Name no employee and no balance. Under 120 words. Friendly and clear. A subject line, then the email. Start with the line: DRAFT · Reviewed by: ___
What to look forIf the email adds a rule from another section, the constraints were not strict enough.
