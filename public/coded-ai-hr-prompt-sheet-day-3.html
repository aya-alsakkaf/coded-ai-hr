How to use this
  1. Watch the trainer first. Then find the same card here.
  2. Download the file on the card. In Copilot Chat, start a new chat and attach it (the + or paperclip button).
  3. Click COPY, paste the request into Copilot, then press Enter.
  4. Check the answer against the file before you trust it: dates, numbers, names and rules.

Answers vary. Copilot may word things differently from the trainer's screen. That is normal, and it is why we check. Use only the fictional Mutla files here, or green tasks from your own work.

Block 2 · Agent Builder

Demo 3.2Agent BuilderWatch, then try

The assistant's instructions, part by part

  1. In Microsoft 365 Copilot, choose New agent, then Configure.
  2. Name, description, then paste the instructions.
  3. Add the five policy files under Knowledge. Test in Try it.
Instructions
You are Mutla HR Policy Helper. You answer Mutla employees' questions about leave, allowances, attendance and training. Answer only from the knowledge files. Give the policy name and section for every answer. Allowances: version 3 applies until version 4 starts on 1 January 2027. Give today's rule first, then the change and its date. Polite, short, plain English. Never give or guess the salary, allowance or personal data of a named person. Never decide a case. If a question needs a personal record, a decision or is not in the files, say so and refer the person to the right HR unit. If the answer depends on the person's grade or situation, ask for it before you answer.
What to look forTest the sensitive question last. It must decline and refer.

Task 3.2Agent BuilderYour turn · 30 min

Build the Mutla HR Policy Helper

  1. New agent → Configure. Name it and write a one-line description.
  2. Paste the instructions from Demo 3.2 on the prompt sheet. Add the five policy files under Knowledge.
  3. In Try it, ask the three test questions. Write a test log: question, answer, pass or fix.
  4. Fix one instruction that failed, then test again. Create the agent.

Task 3.3Copilot Chat + the appsYour turn · 100 min

A tested workflow for a new case, in two parts

  1. Open the capstone case for your track. It is new to you. Part 1 runs to 11:35; part 2 runs 12:15 to 13:30.
  2. Plan the steps: which outputs, which app, which files.
  3. Write five-input requests for each step. Chain at least two Copilot apps.
  4. Review every output with the four-point check.
  5. Save the requests as a reusable prompt set in Word.
