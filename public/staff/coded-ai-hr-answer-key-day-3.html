Job Evaluation and Salary Scaling · Three job descriptions for the new Finance structure

Finance has a new structure. Three jobs need updated job descriptions in the 2026 template, with evidence notes for the Job Evaluation committee. This happens every time a structure changes.

  • Three role information sheets (Accounts Payable Officer, Treasury Analyst, Budget Officer) inside the case file
  • The 2026 job description template
  • The five evaluation factors

Compensation · Answering allowance questions every month

Every month, about 30 employees email Compensation with allowance questions. Build a reusable set that drafts replies from the allowances policy and a monthly summary for your supervisor.

  • Six employee questions from October inside the case file
  • The allowances policy, version 4

Manpower · The monthly vacancy report for Production

Every month, Manpower sends the Production division a vacancy report: open positions, how long each has been open, and what is blocked. Build a reusable set for it.

  • October vacancy data for Production inside the case file
  • Last month's report as an example of the format

Personnel and Administration · Monthly leave-balance reminders and exceptions

Every month, Personnel reminds employees with high leave balances to plan their leave, and lists exceptions for line managers. Build a reusable set for it.

  • October leave-balance extract (employee codes only) inside the case file
  • The leave policy

Learning and Development · Course feedback summaries and nominations

After every course, L&D summarizes the feedback for the trainer and the unit heads, then sends nominations for the next course. Build a reusable set for it.

  • Feedback comments from three October courses inside the case file
  • The training policy
