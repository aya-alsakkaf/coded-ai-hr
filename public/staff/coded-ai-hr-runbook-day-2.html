Compare two versions

No file needed.
▶Say“A change you can point to has a section number. Without it, nobody can check.”
  1. Open a new chat. Paste the request with both short texts in it.
  2. Check each row against the two texts.
Prompts: paste in this order
Compare two versionsCompare the old and new attendance rules below. List every change in a table: section, old text, new text. Staff will ask what changed. I answer only from the approved text. Old, section 2: work starts at 7:00 and ends at 14:00. New, section 2: staff start between 6:30 and 8:00; core hours are 8:00 to 13:00; 7 working hours a day. Old, section 3: 2 permissions a month. New, section 3: 3 permissions a month, up to 2 hours each. Neutral. No opinion on which version is better. Use only the two texts above. Write No change for any section that did not change.

13Task 2.6 · Copilot Chat + the appsYour turn · 45 min · on your own

One case, four outputs

Files: mutla-case-je-reevaluation-request.docx, mutla-case-compensation-allowance-update.docx, mutla-case-manpower-new-section.docx, mutla-case-personnel-attendance-change.docx, mutla-case-ld-training-requests.docx, mutla-attendance-rules-2026.docx, mutla-training-policy-2026.docx, mutla-jd-template-2026.docx, mutla-job-evaluation-factors.docx, mutla-allowances-policy-v4.docx, mutla-policy-change-brief.docx
▶Say“Same five inputs, four apps, one case from your own unit. Then the review.”
  1. Open the case file for your unit track.
  2. Output 1: a Word summary of the case. Output 2: an Outlook message to the right person.
  3. Output 3: a brief for the meeting in the case. Output 4: an Excel summary or a PowerPoint briefing.
  4. Run the four-point review on each output: accuracy, confidentiality, neutrality, source alignment.
Prompts: paste in this order
SummaryYou are an HR officer at Mutla. Summarize the attached case in one page: the facts, the dates, who owns what and the open questions. Use only the case file. Neutral and plain English.
ReviewReview this draft against the attached case file. Check four things: accuracy of every date and number, any personal or confidential detail, neutral wording, and that every point comes from the file. List any problem with the line it is in.
What you should seeFour outputs per participant, each matching the case file's dates and numbers, with no personal data and no decision that belongs to a person.
+Finished earlyWrite your own review request for the riskiest output in your case, without copying the Review request on the prompt sheet. Add it to the Prompt Bank under Review.
!If it failsShort of time: two outputs done well beat four done fast. The result is on the backup results page.
