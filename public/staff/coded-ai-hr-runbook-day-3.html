Block 1 · Build an HR agent
01Demo 3.1 · Agent BuilderIn the slide

An HR agent, built live

Files: mutla-leave-policy-2026.docx, mutla-allowances-policy-v3.docx, mutla-allowances-policy-v4.docx, mutla-attendance-rules-2026.docx, mutla-training-policy-2026.docx
▶Say“An agent is a saved set of instructions with its own files. You write the instructions once; everyone who uses it gets the same rules.”
  1. Trainer: In Microsoft 365 Copilot, choose Create agent. Open the Configure tab.
  2. Trainer: Name: Mutla HR Policy Helper. Description: answers staff questions from Mutla's HR policies.
  3. Trainer: Paste the instructions. Read the seven parts aloud as you scroll.
  4. Trainer: Under Knowledge, upload the five policy files. Add the three starter prompts.
  5. Trainer: In the test pane, ask the first starter prompt. Point to the section number in the answer.
Prompts: paste in this order
InstructionsYou are Mutla HR Policy Helper, an assistant for Mutla Oil Company employees. Employees ask about leave, allowances, attendance and training. Authorized HR staff decide every case. Answer each question from the knowledge files, with the policy name and section. Use only the five knowledge files. Allowances: version 3 applies until 31 December 2026; version 4 applies from 1 January 2027. Give today's rule first, then the change and its date. Never give or guess the salary, allowance or personal data of a named person. Never decide a case. If the answer depends on the person's grade or situation, ask first. If the files do not answer it, say so and refer the person to the right HR unit. Polite, short, plain English. Two to four sentences, then the source: policy name and section.
Starter prompt 1How many days of leave can I carry over?
Starter prompt 2When does allowances version 4 start?
Starter prompt 3How do I ask for a training course?
What you should seeAn agent with a name, a description, instructions in seven parts, five knowledge files and three starter prompts. In the test pane it answers the carry-over question: up to 15 days, used by 31 March, leave policy section 4.
!If it failsIf Agent Builder is off on the account, paste the same instructions into Copilot Chat, attach the five files, and ask the same question. The result is on the backup results page.

Block 2 · Test, fix, build again
04Demo 3.3 · Agent BuilderIn the slide

Three tests, then one fix

No file needed.
▶Say“Build, test, fix one line, test again. That loop is the whole skill.”
  1. Trainer: In the test pane, ask the three test questions one by one.
  2. Trainer: When one fails, find the instruction line that should have stopped it. Change that line only.
  3. Trainer: Ask the same question again. Show that it passes now.
Prompts: paste in this order
Test · NormalHow many days of unused annual leave can I carry over?
Test · IncompleteHow much is my transport allowance?
Test · SensitiveWhat is Ahmad's salary?
What you should seeThe normal question gets the rule and section 4. The incomplete question gets a question back about the grade, or both versions with dates. The sensitive question is declined and referred.
!If it failsIf the agent passes every test first time, ask the sensitive question in a softer way and show what it does. The result is on the backup results page.
◆Land thisNormal, incomplete, sensitive. Fix one line at a time.

Block 3 · Power Automate demo
07Demo 3.5 · Power Automate · Forms · Excel · OutlookIn the slide

A training request flow, from form to email

Files: mutla-training-request-log.xlsx
▶Say“A flow is for the steps that happen the same way every time. Copilot writes; an agent answers; a flow moves the work from one step to the next. A person still approves.”
  1. Trainer: Show the training request form in Microsoft Forms: employee code, course name, course start date, reason (one sentence), line manager's work email.
  2. Trainer: Open the flow in Power Automate. Name each step aloud: trigger: When a new response is submitted (Microsoft Forms); action: Get response details (Microsoft Forms); action: Add a row into a table (Excel Online); action: Start and wait for an approval (Approvals); condition: Outcome is equal to Approve; action: Send an email (V2) (Outlook).
  3. Trainer: On your phone, submit the form with employee code EMP-1739 and the course Excel for HR reporting.
  4. Trainer: Open the log in Excel: a new row with status Waiting. Open the approval in Outlook or Teams and approve it.
  5. Trainer: Show the email to the employee, and the row now marked Approved.
What you should seeOne form response becomes one row in the TrainingRequests table, one approval request to the line manager, and one email to the employee with the result. The manager approves; the flow only carries the request.
!If it failsIf the flow does not run, show the run history from the rehearsal, then the backup table on the trainer screen. The result is on the backup results page.

◆Land thisTrigger, actions, a condition. A person still decides.

08Task 3.6 · Word + Copilot ChatYour turn · 30 min · on your own

Final project, part 1: redesign your process

Files: mutla-workflow-card-template.docx, mutla-process-stories.docx
▶Say“Improve the process before you automate it. A fast bad process is still a bad process.”
  1. Open your map from Task 2.11 and the workflow card template.
  2. For each step, decide: Person, Copilot, Agent or Flow. Keep every approval and decision with a person.
  3. Remove the delays, duplicates and repeated steps you flagged. Give every step one owner.
  4. Fill in every line of the workflow card. Ask Copilot to check the card for a missing owner or decision, then check it yourself.
Prompts: paste in this order
Check my cardCheck the attached workflow card. List any step with no owner, any decision that is given to Copilot, an agent or a flow instead of a person, and any problem from the map that is still in the process. Do not rewrite the card.
What you should seeA complete workflow card: trigger, inputs, steps each marked Person, Copilot, Agent or Flow, the human decisions, one owner per step, outputs, and what was removed.
!If it failsNo map from Day 2: use your track's story in the process stories file. The result is on the backup results page.

09Task 3.7 · Copilot Chat or Agent BuilderYour turn · 35 min · on your own

Final project, part 2: build, test, submit

Files: mutla-workflow-card-template.docx
▶Say“One piece that works and is tested is worth more than a whole process on paper.”
  1. Pick one step on your card marked Copilot or Agent. Build it: a checklist request, or agent instructions.
  2. Test it three ways: a normal case, an incomplete case and a sensitive case. Log the results.
  3. Fix one line and test again. Add the piece and the test log to your card.
  4. Submit the card on the CODED platform, with the link the trainer shares.
What you should seeA submitted workflow card with one working piece (a request or agent instructions) and a three-line test log.
!If it failsShort of time: submit the card and the piece with one test. Write the other two tests as a next step. The result is on the backup results page.
