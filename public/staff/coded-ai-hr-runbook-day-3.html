  • Day 2: open forms.cloud.microsoft with the training account and check that New Form shows the Draft with Copilot box. If it does not, prepare the Quick import fallback (a Word file with the nine questions).
  • Day 2: open the training mailbox in Outlook and check that the thread Orientation day for new joiners, Sunday 6 December is there, with three messages.
  • Day 3: open Agent Builder (Create agent) once before the day starts. If it is missing, use the fallback in the runbook.
  • Day 3: check that the Power Automate demo video plays with sound on the presenting laptop. Until the video is recorded, present the six steps on the slide.
  • Open this runbook, the backup results and the answer key on your own screen.
  • Copy today's sample files to the presenting laptop and to a USB stick.
  • Test the projector with the deck at full screen (F). Open the backup results for today on your own screen, in case Copilot is slow.

01Demo 3.1 · Agent BuilderIn the slide

An HR agent, built live

Files: mutla-leave-policy-2026.docx, mutla-allowances-policy-v3.docx, mutla-allowances-policy-v4.docx, mutla-attendance-rules-2026.docx, mutla-training-policy-2026.docx
▶Say“An agent is a saved set of instructions with its own files. You write the instructions once; everyone who uses it gets the same rules.”
  1. Trainer: In Microsoft 365 Copilot, choose Create agent. Open the Configure tab.
  2. Trainer: Name: Mutla HR Policy Helper. Description: answers staff questions from Mutla's HR policies.
  3. Trainer: Paste the instructions. Read the five parts aloud as you scroll.
  4. Trainer: Under Knowledge, upload the five policy files. Add the three starter prompts.
  5. Trainer: In the test pane, ask the first starter prompt. Point to the section number in the answer.
Prompts: paste in this order
InstructionsYou are Mutla HR Policy Helper, an assistant for Mutla Oil Company employees. Employees ask about leave, allowances, attendance and training. Authorized HR staff decide every case. Answer each question from the knowledge files, with the policy name and section. Use only the five knowledge files. Allowances: version 3 applies until 31 December 2026; version 4 applies from 1 January 2027. Give today's rule first, then the change and its date. Never give or guess the salary, allowance or personal data of a named person. Never decide a case. If the answer depends on the person's grade or situation, ask first. If the files do not answer it, say so and refer the person to the right HR unit. Polite, short, plain English. Two to four sentences, then the source: policy name and section.
Starter prompt 1How many days of leave can I carry over?
Starter prompt 2When does allowances version 4 start?
Starter prompt 3How do I ask for a training course?
What you should seeAn agent with a name, a description, instructions in five parts, five knowledge files and three starter prompts. In the test pane it answers the carry-over question: up to 15 days, used by 31 March, leave policy section 4.
!If it failsIf Agent Builder is off on the account, paste the same instructions into Copilot Chat, attach the five files, and ask the same question. The result is on the backup results page.

Block 2 · Test, fix, build again
04Demo 3.3 · Agent BuilderIn the slide

Three tests, then one fix

No file needed.
▶Say“Build, test, fix one line, test again. That loop is the whole skill.”
  1. Trainer: In the test pane, ask the three test questions one by one.
  2. Trainer: When one fails, find the instruction line that should have stopped it. Change that line only.
  3. Trainer: Ask the same question again. Show that it passes now.
Prompts: paste in this order
Test · NormalHow many days of unused annual leave can I carry over?
Test · IncompleteHow much is my transport allowance?
Test · SensitiveWhat is Ahmad's salary?
What you should seeThe normal question gets the rule and section 4. The incomplete question gets a question back about the grade, or both versions with dates. The sensitive question is declined and referred.
!If it failsIf the agent passes every test first time, ask the sensitive question in a softer way and show what it does. The result is on the backup results page.
◆Land thisNormal, incomplete, sensitive. Fix one line at a time.

A training request flow, from form to email (video)

Files: mutla-training-request-log.xlsx

Trainer: Play the demo video of the flow: trigger: When a new response is submitted (Microsoft Forms); action: Get response details (Microsoft Forms); action: Add a row into a table (Excel Online); action: Start and wait for an approval (Approvals); condition: Outcome is equal to Approve; action: Send an email (V2) (Outlook).

  3. Trainer: Placeholder until the video is recorded: walk through the six steps on the slide.

Block 4 · Map a workflow
08Demo 3.6 · Copilot ChatIn the slide

A story into a step table

No file needed.
▶Say“First we see the process as it really is. We improve it after we can see it.”
  1. Trainer: Open a new Copilot Chat. Paste the request: the story is inside it.
  2. Trainer: Read the table aloud. Ask the room which problem Copilot missed, if any.
  3. Trainer: Point out that Copilot flags the problems and does not fix them.
Prompts: paste in this order
Map a storyTurn the process story below into a step table. The story: To book an external trainer, the Training Coordinator emails three providers for prices. She copies each price into a spreadsheet by hand. Her manager approves the choice by email, usually after three days. She then emails Procurement, who asks for the same three prices again. Nobody tells the trainer the room number until the day before. Do not improve the process. Only map it. Flag each step that has a delay, duplicated effort, unclear ownership or a repetitive step. Mark every step where a person must decide. A table: step, who, what happens, input, output, wait, problem, a person decides?
What you should seeFive or six steps. Delay: the manager's approval after three days. Duplicated effort: prices copied by hand, then asked for again by Procurement. Unclear ownership: nobody tells the trainer the room. A person decides: the manager approves the choice.
!If it failsShow the backup table on the trainer screen. The result is on the backup results page.
◆Land thisMap it as it is. Flag the problems. Do not fix them yet.
