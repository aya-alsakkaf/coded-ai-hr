Pre-flight (30 minutes before)

  • Sign in to Microsoft 365 Copilot on the presenting laptop with the training account. Test one file upload (the leave policy).
  • Read the license label under your name on the Microsoft 365 home page: Copilot Chat (Basic), M365 Copilot (Basic) or M365 Copilot (Premium). Day 2 app demos need an M365 Copilot label (Basic or Premium); Teams recaps need Premium.
  • Day 3: open Agent Builder (New agent) once before the day starts. If it is missing, use the fallback in the runbook.
  • Open this runbook, the backup results and the answer key on your own screen.
  • Copy today's sample files to the presenting laptop and to a USB stick.
  • Test the projector with the deck at full screen (F). Step through one prompt-player slide and press R to reset it.

Adapt a suggested prompt

02Task 3.1 · Copilot Chat · Prompt GalleryYour turn · 10 min · on your own

Save your best three

Files: mutla-prompt-bank-template.docx, mutla-catchup-prompt-bank.docx
▶Say“The best request is the one you already tested. Save it where you will find it.”
  1. Open your Prompt Bank (or mutla-catchup-prompt-bank.docx if you missed a day).
  2. Pick your three best tested requests.
  3. Save each one in the Prompt Gallery under Your Prompts, with a clear name.
  4. Organize the Prompt Bank by task: Draft, Compare, Summarize, Review.
What you should seeThree requests saved under Your Prompts with clear names, and a Prompt Bank organized by task.
+Finished earlyShare one prompt with a team, if your account has one.

Block 2 · Agent Builder
03Demo 3.2 · Agent BuilderIn the slide

The assistant's instructions, part by part

Files: mutla-leave-policy-2026.docx, mutla-allowances-policy-v3.docx, mutla-allowances-policy-v4.docx, mutla-attendance-rules-2026.docx, mutla-training-policy-2026.docx
▶Say“Instructions are the script, knowledge is the binder, Try it is the rehearsal.”
  1. In Microsoft 365 Copilot, choose New agent, then Configure.
  2. Name, description, then paste the instructions.
  3. Add the five policy files under Knowledge. Test in Try it.
Prompts: paste in this order
InstructionsYou are Mutla HR Policy Helper. You answer Mutla employees' questions about leave, allowances, attendance and training. Answer only from the knowledge files. Give the policy name and section for every answer. Allowances: version 3 applies until version 4 starts on 1 January 2027. Give today's rule first, then the change and its date. Polite, short, plain English. Never give or guess the salary, allowance or personal data of a named person. Never decide a case. If a question needs a personal record, a decision or is not in the files, say so and refer the person to the right HR unit. If the answer depends on the person's grade or situation, ask for it before you answer.
What you should seeAn assistant that answers from the four policies with the section, asks for the grade before an allowance answer, and declines a named person's salary.
!If it failsIf Agent Builder is not available, show the backup tests and build the same instructions as a saved request in Copilot Chat. The result is on the backup results page.

04Task 3.2 · Agent BuilderYour turn · 30 min · on your own

Build the Mutla HR Policy Helper

Files: mutla-leave-policy-2026.docx, mutla-allowances-policy-v3.docx, mutla-allowances-policy-v4.docx, mutla-attendance-rules-2026.docx, mutla-training-policy-2026.docx
▶Say“Build it, then test it with hard questions. A test you did not run is a problem you will meet later.”
  1. New agent → Configure. Name it and write a one-line description.
  2. Paste the instructions from Demo 3.2 on the prompt sheet. Add the five policy files under Knowledge.
  3. In Try it, ask the three test questions. Write a test log: question, answer, pass or fix.
  4. Fix one instruction that failed, then test again. Create the agent.
Prompts: paste in this order
Test · NormalHow many days of unused annual leave can I carry over?
Test · IncompleteHow much is my transport allowance?
Test · SensitiveWhat is Ahmad's salary?
What you should seeA working assistant and a three-line test log. It cites the section, asks for the grade before the transport answer, and declines the named salary.
+Finished earlyExtend the assistant to a second scenario: new joiners in their first month, with questions about leave, allowances and their first training course. Add two starter prompts for it, then run a fourth test with a question the files do not cover. It must refer the person to HR.
!If it failsNo Agent Builder on your account: save the instructions as a request in Copilot Chat, attach the five policy files, and run the same three tests. Or pair with a neighbor. The result is on the backup results page.

05Task 3.3 · Copilot Chat + the appsYour turn · 100 min · on your own

A tested workflow for a new case, in two parts

Files: mutla-capstone-je-salary.docx, mutla-capstone-compensation.docx, mutla-capstone-manpower.docx, mutla-capstone-personnel.docx, mutla-capstone-ld.docx, mutla-jd-template-2026.docx, mutla-job-evaluation-factors.docx, mutla-leave-policy-2026.docx, mutla-allowances-policy-v4.docx, mutla-training-policy-2026.docx, mutla-prompt-bank-template.docx
▶Say“A new case proves the method, not your memory. Plan, request, review, save.”
  1. Open the capstone case for your track. It is new to you. Part 1 runs to 11:35; part 2 runs 12:15 to 13:30.
  2. Plan the steps: which outputs, which app, which files.
  3. Write five-input requests for each step. Chain at least two Copilot apps.
  4. Review every output with the four-point check.
  5. Save the requests as a reusable prompt set in Word.
Prompts: paste in this order
Plan the workflowYou are an HR officer at Mutla. Read the attached capstone case. List the steps to complete this recurring task with Copilot: for each step, the output, the app, the files and the check. Do not do the task yet.
What you should seeA finished set of outputs for the case and a reusable prompt set in Word: every request has the five inputs, cites its files and ends with a check.
+Finished earlyConnect the workflow to your HR assistant, or turn one request into a starter prompt.
!If it failsShort of time: one step done and reviewed is better than four unchecked. The result is on the backup results page.

06Task 3.4 · A colleague + CopilotYour turn · 20 min · in pairs

Peer test

Files: mutla-capstone-fresh-input.docx
▶Say“If a colleague needs you to explain your prompt set, it is not finished yet.”
  1. Swap with a colleague from a different unit.
  2. Run their prompt set on their track's fresh input in mutla-capstone-fresh-input.docx. Ask them nothing.
  3. Write down where it failed or where you had to guess.
  4. Swap back. Fix your set and write the fix into it.
What you should seeEach pair finds at least one place where a set depended on something only its owner knew, and writes one fix into it.
+Finished earlyRun a second colleague's set.
!If it failsOdd number: a group of three, in a circle. The result is on the backup results page.
