Day 3 · HR Agents, Workflows and an Introduction to Power Automate

HR Agents, Workflows and an Introduction to Power Automate

Put a request on a timer, use two built-in agents, build and test your own HR agent in Agent Builder, see three Power Automate flows run on their own, and map an HR process from request to result.

Day 3 of 3 · Thursday 19 Nov 09:00-15:00 In person · CODED, Alsharekh room, Frontend Campus
The day in one line · 09:00-15:00

Day brief

Day 3 starts with Copilot working for you on a timer: the trainer schedules a tested request to run every week. Then you use agents that Microsoft built: Prompt Coach improves one of your Prompt Bank requests, and Researcher answers a public HR question with sources that you check. Then you build your own HR agent in Agent Builder with five policy files, and test it with a normal, an incomplete and a sensitive question. Before lunch the trainer explains what automation means and when to automate, then talks you through three recorded Power Automate flows: a training request approval, a weekly AI brief for vendors, and a vendor quotation that AI reads and scores. After lunch you map a whole HR process: every step, every owner, every wait and every human decision.

You build today: A better request from Prompt Coach, a tested HR agent and a map of one HR process.

What you will be able to do

  • Explain what a scheduled prompt does, and use a built-in agent such as Prompt Coach or Researcher, checking what it gives you.
  • Build an HR agent with the prompt checklist and approved files, and test it with a normal, an incomplete and a sensitive question.
  • Explain when to automate, and name the trigger, actions, connectors and output of a Power Automate flow.
  • Map an HR process from request to result, and mark the delays, duplicates, owners and human decisions.
